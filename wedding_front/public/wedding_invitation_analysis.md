# 모바일 청첩장 분석 보고서

제공된 5개의 이미지(1.png ~ 5.png)를 바탕으로 분석된 모바일 청첩장의 구성 요소와 상세 정보입니다.

## 1. 기본 정보 (Main Info)
*   **신랑:** 김철수 (장남)
*   **신부:** 이영희 (장녀)
*   **일시:** 2024년 10월 26일 토요일 오후 1시
*   **장소:** 더 리버사이드 호텔 7층 콘서트홀

## 2. 혼주 정보
*   **신랑 측 부모:** 김영호 · 박순자
*   **신부 측 부모:** 이정식 · 최미경

## 3. 상세 구성 (Page Structure)

### [Page 1] 메인 커버
*   **특징:** 감성적인 폰트와 여백을 활용한 깔끔한 디자인
*   **내용:** 신랑/신부 성함, 예식 날짜, 장소명

### [Page 2] 초대 문구 (Greeting)
*   **내용:** 두 사람의 만남과 새로운 시작을 축복해달라는 인사말
*   **구조:** 인사말 본문 -> 양가 부모님 및 신랑/신부 관계 표기

### [Page 3] 갤러리 (Gallery)
*   **특징:** 스튜디오 웨딩 화보 중심의 그리드 레이아웃
*   **구성:** 여러 장의 사진을 슬라이드하거나 바둑판식으로 배치

### [Page 4] 예식 정보 & 오시는 길 (Location)
*   **달력:** 2024년 10월 달력 이미지, 26일 날짜 강조
*   **지도:** 카카오맵/네이버지도 연동 UI 또는 정적인 지도 이미지
*   **교통편:** 
    *   지하철: 3호선 신사역 5번 출구 도보 5분
    *   버스: 신사역/푸른저축은행 정류장 하차

### [Page 5] 마음 전하실 곳 (Account Information)
*   **신랑측 계좌:** 신한은행 110-xxx-xxxxxx (김철수)
*   **신부측 계좌:** 국민은행 00000-xx-xxxxxx (이영희)
*   **기능:** 계좌번호 복사 버튼 포함

## 4. 추천 추가 기능 (Recommended Features)

실제 신혼부부들이 선호하고 하객들의 편의성을 높일 수 있는 기능들입니다.

### 4.1 편의 및 실무 기능
*   **참석 여부 회신 (RSVP):** 하객의 참석 여부, 식사 인원, 동행인 정보를 수집하여 식수 인원 파악에 활용.
*   **내비게이션 직접 연동:** T맵, 카카오내비, 네이버 지도 앱으로 즉시 연결되는 버튼 제공.
*   **카카오톡 공유 최적화:** 카카오톡 전송 시 전용 썸네일과 버튼이 포함된 메시지 카드(Open Graph) 구성.

### 4.2 금융 편의 기능
*   **간편 송금 연동:** 카카오페이, 토스(Toss) 등 클릭 한 번으로 송금 화면 연결 기능.

### 4.3 감성 및 소통 기능
*   **실시간 방명록:** 하객들이 축하 메시지를 남길 수 있는 공간 (비밀글 기능 포함).
*   **D-Day 카운트다운:** 예식일까지 남은 시간을 메인 화면에 표시하여 기대감 조성.
*   **식전 영상 삽입:** 유튜브/비메오에 업로드된 웨딩 영상을 메인 또는 별도 섹션에 임베드.

### 4.4 보안 및 관리
*   **관리자 페이지:** RSVP 응답 데이터 및 방명록 관리, 엑셀 다운로드 기능.
*   **접속 비밀번호:** 청첩장 보안을 위해 첫 접속 시 비밀번호 입력 단계 추가.
